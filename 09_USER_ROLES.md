# Tujuan

Dokumen ini mendefinisikan role resmi beserta hak akses masing-masing
pengguna.

# Role Resmi

## 1. Super Admin

Hak akses: - Kelola seluruh pengguna - Kelola Admin - Kelola Pengasuh -
Kelola master data - Kelola tahun ajaran & semester - Backup & Restore -
Konfigurasi sistem - Akses seluruh laporan

## 2. Admin

Hak akses: - Kelola data Pengasuh - Tambah/Edit/Nonaktifkan Pengasuh -
Membantu administrasi - Melihat laporan operasional

## 3. Pengasuh

Hak akses: - Kelola data anak - Kelola absensi - Input nilai - Input
perkembangan - Membuat dan mencetak rapor

## 4. Orang Tua / Anak

Hak akses: - Login - Melihat profil - Melihat absensi - Melihat nilai -
Melihat & mengunduh rapor (jika diaktifkan)

Role ini bersifat read-only.

# Aturan

-   Tidak boleh menambah role baru tanpa persetujuan Project Owner.
-   Seluruh permission mengikuti prinsip least privilege.
