# PROJECT CONSTITUTION

**Document ID:** DOC-001  
**Version:** 1.0.0  
**Status:** Approved  
**Project:** e-Raport Sekolah Minggu (Genesis)

---

# Pasal 1 - Dokumentasi

Dokumentasi adalah sumber kebenaran utama proyek. Seluruh implementasi wajib mengacu pada dokumentasi.

# Pasal 2 - Scope

Aplikasi hanya untuk satu gereja dan tidak mendukung multi-gereja.

Tidak termasuk:
- Aplikasi Keuangan
- Warta Jemaat
- Inventaris Gereja

# Pasal 3 - Branding

Nama aplikasi, logo, dan splash screen resmi tidak boleh diubah atau dihapus tanpa persetujuan Project Owner.

# Pasal 4 - User Role

Role resmi hanya:
1. Super Admin
2. Admin
3. Pengasuh
4. Orang Tua / Anak

Tidak boleh menambah role baru tanpa keputusan resmi.

# Pasal 5 - Responsive First

Setiap fitur wajib dirancang untuk Mobile dan Desktop secara bersamaan.

# Pasal 6 - Documentation First

Alur kerja:
Diskusi → Dokumentasi → Persetujuan → Implementasi → Testing → Release

# Pasal 7 - AI Rules

AI wajib:
- Membaca dokumentasi sebelum bekerja.
- Mengikuti arsitektur proyek.
- Menjaga konsistensi kode.

AI dilarang:
- Mengubah arsitektur tanpa izin.
- Mengubah database tanpa izin.
- Menghapus file yang tidak berkaitan.
- Menambah dependency tanpa alasan terdokumentasi.
- Mengubah branding.

# Pasal 8 - Git

Seluruh perubahan menggunakan Git dan GitHub.

Branch utama:
- main
- develop
- feature/*
- bugfix/*
- hotfix/*

# Pasal 9 - Quality

Kualitas lebih diutamakan daripada kecepatan. Task belum dianggap selesai sebelum lolos pengujian sesuai platform target.

# Pasal 10 - Perubahan

Setiap perubahan besar wajib memperbarui dokumentasi terlebih dahulu.
