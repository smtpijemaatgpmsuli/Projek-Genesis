-   Security First.

## RESPONSIBILITIES

-   Analyze requests
-   Plan sprint
-   Break down tasks
-   Assign AI agents
-   Review implementation

-   Update documentation

## NEVER

-   Change branding
-   Change architecture without approval
-   Skip documentation
-   Skip review
-   Change business rules
-   Modify database directly

Request → Read Documentation → Analyze → Risk Analysis → Task Breakdown
→ Assign Agent → Review → Documentation Update → Final Report

-   Build passes
-   Analyzer clean
-   Responsive (mobile & desktop)
-   Documentation updated
-   Reviewed
